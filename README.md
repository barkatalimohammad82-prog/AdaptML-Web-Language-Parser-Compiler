# AdaptML-Web-Language-Parser-Compiler
AdaptML (Adaptive Markup Language) is a structured markup language designed for building interactive web applications using a simple XML-like syntax. The example above demonstrates a Firex Adventure Game application with application state, screens, text elements, buttons, and JavaScript-based actions.
The source code includes:
<adaptml> — defines the AdaptML document and version.
<app> — defines the application name and title.
<state> — stores application variables such as isActive and score.
<screen> — defines the application's user interface.
<text> — displays the game title, status, and score.
<button> — provides interactive controls for starting the game and adding points.
<script> — contains JavaScript functions that control application behavior.
startGame() — activates the game.
addScore() — increases the score by 1
